# زاد وورك سبيس — لاندنج بيدج

موقع Zad Workspace (كوورك سبيس في أسيوط). صفحة واحدة (single page)، من غير أي backend أو build step، جاهزة للرفع على أي استضافة ملفات ثابتة (static hosting).

## الملفات المهمة

| الملف | إيه هو |
|---|---|
| `zad-workspace-landing.html` | **الصفحة نفسها.** ده الملف اللي يترفع كـ `index.html` على أي استضافة. |
| `zad-workspace_images.js` | كل صور الموقع متحوّلة WebP ومحفوظة base64 جوه `window.ZAD_IMAGES`. لازم يترفع في **نفس الفولدر** بجمب الـ HTML بالظبط، لأنه بيتنادى بمسار نسبي (`<script src="zad-workspace_images.js">`). |
| `build-images.py` | سكريبت بايثون بيعيد بناء `zad-workspace_images.js` من الصور الأصلية، لو حبينا نغيّر أو نضيف صورة. محتاج فولدر اسمه `ZAD PICS` فيه الصور الأصلية (HEIC/JPG) — **الفولدر ده مش موجود في الريبو ده**، هو على جهاز خديجة بس. لو محتاجين نغيّر صورة، خديجة تبعت الصورة الجديدة الأول. |
| `ZAD_WORKSPACE_PROJECT_BRIEF.md` | ملخص كل القرارات والتفاصيل اللي اتاخدت وقت التصميم (الألوان، الأرقام الحقيقية، القواعد، القرارات المرفوضة، إلخ). **لو حد هيكمل شغل على الموقع (حتى لو باستخدام Claude Code أو أي AI تاني)، يقرا الملف ده الأول قبل أي تعديل.** |

## إزاي تشغّل الموقع محليًا

مفيش أي build step. فتح الملف مباشرة كـ `file://` مش هيحمّل الصور صح بسبب قيود المتصفح، فشغّلي سيرفر بسيط بدله:

```bash
python -m http.server 8000
```

وبعدين افتحي `http://localhost:8000/zad-workspace-landing.html`

## إزاي تنشره على دومين حقيقي

الموقع كله ملفين ثابتين بس، يشتغلوا على أي استضافة (Netlify، Vercel، GitHub Pages، أو استضافة تقليدية بالـ FTP):

1. ارفع `zad-workspace-landing.html` (سمّيه `index.html`) و`zad-workspace_images.js` في نفس الفولدر بالظبط.
2. خلاص. مفيش أي إعدادات تانية، ولا متغيرات بيئة، ولا build step.

## Branches و tags

- **`main`** — النسخة الحالية المنشورة (التصميم الجديد).
- **`master`** — النسخة الأصلية قبل التجديد، محفوظة كمرجع.
- **`v0`** — نقطة قبل شيل الخلفيات الملوّنة.
- **`v2`** — نفس نسخة `main` الحالية، متعلّم عليها كنقطة مرجعية.
